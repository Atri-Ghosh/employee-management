# Employee Management System 🏢

An interactive, responsive Employee Management web application built with **React** and **Tailwind CSS**. Designed to help organizations efficiently display, filter, create, update, and manage personnel records with real-time KPI statistics and data export capabilities.

---

## 🚀 Features & Requirements Fulfilled

* **Interactive Employee Dashboard:** Displays all staff members in a responsive data table.
* **CRUD Operations:**
  * **Create:** Add new employee records via a clean modal form.
  * **Read:** View detailed records including departments, roles, statuses, and salaries.
  * **Update:** Edit existing employee details dynamically.
  * **Delete:** Remove records with confirmation alerts.
* **KPI Summary Statistics:** Dynamic metric cards showing Total Employees, Active Staff, Average Salary, and Department counts.
* **Department Filtering & Search:** Filter employees instantly by department tags or search by name and email.
* **Persistent Storage:** Leverages browser `localStorage` so added and modified records persist across page refreshes.
* **CSV Export:** Download the currently filtered employee directory directly as a `.csv` file.

---

## 🛠️ Tech Stack

* **Frontend:** React (Vite)
* **Styling:** Tailwind CSS
* **Icons & UI Utilities:** Lucide React
* **State Management & Persistence:** React Hooks (`useState`, `useEffect`, `localStorage`)
